# 专注电台

播放器在计算器上方。点击播放后，默认按歌单连续播放并循环；可切换单曲循环、随机播放和顺序播放（末曲结束后停止）。支持上一首、下一首、进度拖动、音量、静音及展开歌单。每首歌都有独立 SVG 插画封面，主封面和选中歌单同步更新。动画跟随页面的暂停动效按钮和系统减少动态效果设置。

浏览器首次访问需要用户点击播放。刷新页面不自动出声，只记住歌曲、音量、静音和播放模式；播放进度不保存。音频预加载关闭，点播放才请求文件。加载失败有重试提示，不影响计算或历史记录。

曲目配置在 `src/music-library.js`，播放器在 `src/MusicPlayer.vue`。添加音乐时，将有授权的 MP3 放入 `public/music/`，封面 SVG 放入 `src/assets/music/`，在配置中填写 id、标题、作者、时长（秒）、相对音频地址、封面 import 和配色，同时更新署名与文件校验清单。首次播放后以音频实际时长显示。

生产通过 Nginx 提供本地音频，支持 Range 请求用于拖动进度；CSP 的 media-src 仅允许本站，不需要任何音乐 API 密钥。记录服务和数据库不因音乐功能发生变化。

本次曲目来源与授权见 `public/music/credits.md`，播放器封面为项目原创插画。
